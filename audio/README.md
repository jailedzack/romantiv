# Audio Folder

Place your romantic song here with the filename:

- our-song.mp3

Supported formats: MP3, WAV, OGG (update the HTML if using a different format)

For best results:
- Use MP3 format for best browser compatibility
- Recommended bitrate: 128kbps - 192kbps (good quality, reasonable file size)
- Keep file size under 5MB for faster loading
- Consider using a song that has meaning to both of you!

Note: Modern browsers may block autoplay until the user interacts with the page.
The code includes an autoplay attempt on load, but the play button will always work.
