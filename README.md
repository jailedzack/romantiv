# 💕 Happy 9 Monthsary! - Anniversary Website

A beautiful, interactive anniversary website built with modern web technologies.

## 🎨 Features

- ✨ Interactive canvas background with floating hearts/particles
- 🎵 Glassmorphism audio player with autoplay support
- ⏱️ Live relationship timer (Years → Seconds)
- 💌 3D fold-out envelope with confetti burst & love letter modal
- 📜 Scroll-driven timeline with smooth animations
- 📸 Polaroid memory grid with lightbox viewer
- 💖 Click/tap particle explosions

## 📁 Setup Instructions

### 1. Add Your Photos

Place your photos in the `images/` folder with these names:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`
- `photo6.jpg`

Or update the paths in `index.html` to match your filenames.

### 2. Add Your Song

Place your romantic song in the `audio/` folder:
- `our-song.mp3`

**Note:** Modern browsers may block autoplay until the user interacts with the page. The code attempts autoplay on load, but the play button will always work.

### 3. Customize Content

Open `index.html` and look for `<!-- CUSTOMIZE:` comments to easily edit:
- Relationship start date (line ~341)
- Timeline milestones and dates
- Photo captions
- Love letter text
- Audio file path

## 🚀 Deploy to GitHub Pages

1. **Create a new repository on GitHub** (or use existing one)

2. **Push your files:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit - 9 monthsary website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```

3. **Enable GitHub Pages:**
   - Go to your repository on GitHub
   - Click **Settings** → **Pages**
   - Under "Source", select **main** branch
   - Click **Save**

4. **Access your site:**
   Your website will be live at: `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`

## 🎯 Browser Compatibility

Works on all modern browsers:
- Chrome/Edge (recommended)
- Firefox
- Safari
- Mobile browsers (iOS Safari, Chrome Mobile)

## 📝 Notes

- Images should be optimized for web (under 500KB each recommended)
- Audio file should be under 5MB for faster loading
- The site is fully responsive and mobile-friendly
- No password/lock screen - opens directly to the celebration!
